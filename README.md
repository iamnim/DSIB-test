# Društvo Sožitje Ilirska Bistrica: predogled

Statični predogled spletne strani z izmišljenimi podatki. Obrazci ne shranjujejo ničesar.

- Javna stran: index.html
- Članski portal: m-clani.html (ali Prijava z kateremkoli e-naslovom)
- Skrbništvo: a-admin.html (ali Prijava z e-naslovom, ki vsebuje »admin«)

Zelena vrstica na dnu vsake strani preklaplja med vsemi tremi deli.
